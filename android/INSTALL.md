# Install Cinejoy TV on an Android TV box (USB)

1. Copy `CinejoyTV.apk` to a USB stick and plug it into the box.
2. On the box, open a file manager (for example **File Commander**, **X-plore**,
   or **FX File Explorer** from the Play Store, or the box's own "Files" app).
3. Open the USB stick and select `CinejoyTV.apk`.
4. If it asks, allow **Install unknown apps** for that file manager
   (Settings → Apps → Security / Device preferences → Unknown sources).
5. Press **Install**, then **Open**.

The app appears on the home screen as **Cinejoy TV**.

## Remote

| Where | Button | What it does |
|---|---|---|
| Browsing | ◀ ▲ ▼ ▶ | Move the green focus box |
| Browsing | OK | Open / press |
| Browsing | Back | Go back a page |
| Home page | Back | Jump to the bottom menu; Back again exits |
| Search box | OK | Open the on-screen keyboard |
| Watching | OK / ⏯ | Play / pause |
| Watching | ◀ ▶ (or ⏪ ⏩) | Skip 10 seconds |
| Watching | Back | Leave the player |

## Updating

Install a newer `CinejoyTV.apk` the same way; it replaces the old one and keeps
your settings.
